# 比邻到门首页设计稿

本目录为本地 UI 评审文件，未部署到服务器，未修改 deploy/index.html。

双击 index.html 查看三个方案入口。每个方案提供独立 PC 和移动端 HTML，共用 styles.css 与 interactions.js；移动版在桌面浏览器中限制为手机宽度，PC 版也支持响应式显示。浏览时保留本目录文件完整。

- v01：蓝色服务门户。
- v02：绿色包裹工作台。
- v03：暖色品牌生活。

所有账号、订单、状态和识别码均为演示数据。弹窗、预报表单、估算输入仅用于交互评审，不提交业务数据，不提供真实价格。

本地 Edge 自动检查覆盖每页 320、375、390、430、1440px 宽度，检查横向溢出、仓库弹窗和估算弹窗。截图为本地浏览器输出。重新生成：node generate.cjs；验证：node verify.cjs（依赖当前机器的 bundled Playwright 与 Edge）。

待真机验证：微信内置浏览器的动态可视区域、软键盘、底部安全区、剪贴板权限和 dialog 支持。未以桌面浏览器检查代替微信真机验收。
